## The Problem

Every day, millions of small business owners, farmers, NGO workers, and educators make decisions that affect their livelihoods — based on gut feeling, not evidence. Not because the data doesn't exist. Because the tools to understand it cost huge money, demand technical training, assume English, and store confidential data on servers they don't control. The global analytics market is worth billions of dollar, yet 80% of the world is completely locked out.

This is not a technology gap. It is a human crisis.

---

## The Solution

**Sepiru AI** is a free, privacy-first, AI-powered data intelligence platform that transforms any CSV, Excel file, or photograph of a handwritten register into analyst-grade insights — in 14 languages, with zero login, zero cloud storage, and zero cost.

Powered by **Google Gemini 2.0 Flash** as the primary intelligence engine, with automatic fallback to Groq's LLaMA 3.3 70B, Sepiru AI delivers nine interconnected capabilities in one platform — accessible from any browser, by any user, anywhere in the world.

## 🚀 Quick Start

```bash

cd Sepiru-AI
pip install -r requirements.txt
# Get free key from aistudio.google.com and console.groq.com
# Add the key in .env file

```
